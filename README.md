# Оно тебе надо

Проектная работа КМ-П1 «Фронтенд-разработка»: лендинг аукциона «Оно тебе надо» — аукциона вещей, в которые никто не верил.

Репозиторий: https://github.com/Vondre1/ono-tebe-nado-ad

## Что сделано

- Семантическая разметка: `header`, `main` с тремя `section` (обложка, лоты, об аукционе), `footer`, `nav`, `address`, `article`.
- Шапка и подвал свёрстаны на CSS Grid, меню, карточки и абзацы — на Flexbox с `gap`.
- Переиспользуемый полупрозрачный `.overlay` на обложке и в карточках (абсолютное позиционирование внутри `position: relative`).
- Блок адреса `.address` общий для шапки и подвала, ссылки `tel:` и `mailto:`.
- Список карточек переносит лишние карточки на новую строку, блоки растягиваются под больший объём текста.
- Подключён локальный шрифт Raleway (woff2 → woff).

## Технологии

HTML5, CSS3 (Grid, Flexbox, позиционирование), БЭМ-именование классов.

## Структура

```
index.html
styles/   global.css — сброс и общие стили, style.css — стили страницы
fonts/    Raleway и fonts.css с @font-face
images/   фоны, логотипы, иконки соцсетей
```

## Как открыть

Открыть `index.html` в браузере — страница работает без сервера. Макет рассчитан на ширину 1100 px.
